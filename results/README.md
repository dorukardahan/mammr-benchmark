# Results Directory

This directory is for sanitized public v0.1 rerun outputs.

Do not copy private VPS result JSONs here.

Acceptable files:

- results generated by `scripts/run_embedding_eval.py`
- aggregate summaries derived from public reruns
- full-corpus, held-out, and reranker summaries generated from public-safe text
- no raw private memory text
- no vector caches unless explicitly sanitized and reviewed

Recommended naming:

```text
qwen3-0.6b-q8_0.json
qwen3-0.6b-q8_0-rerun-YYYYMMDD.json
qwen3-0.6b-q8_0-pinned-YYYYMMDD.json
snowflake-arctic-l-v2-q8_0.json
bge-m3-q8_0.json
jina-v3-q8_0.json
```

Historical Qwen3 diagnostic files:

- `qwen3-0.6b-q8_0.json` - first diagnostic run against an older sanitized public candidate. This is not a current public comparison result.
- `qwen3-0.6b-q8_0-rerun-20260505.json` - audited-dataset diagnostic rerun. This is not a current public comparison result.

Current public comparison files:

- `*-pinned-20260506.json` - pinned four-model local-GGUF public rerun set with embedded backend metadata.
- `retrieval/*20260506.json` - full public corpus plus synthetic-distractor retrieval results.
- `heldout/*20260506.json` - held-out mini-set retrieval results.
- `reranker/*20260506.json` - sanitized public top-10 same-category reranker matrix.
- `strong-evidence-summary.json` - machine-readable summary of the 2026-05-06 evidence pass.

Before publishing or sharing, run:

```bash
python3 scripts/public_release_preflight.py
```
